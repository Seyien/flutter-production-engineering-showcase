# Public media policy / Public medya politikası

This directory is reserved for portfolio-safe diagrams, screenshots, and preview media. No production asset has been copied here.

Bu klasör, portföyde güvenle yayımlanabilecek diyagram, ekran görüntüsü ve önizleme medyası için ayrılmıştır. Buraya hiçbir üretim varlığı kopyalanmamıştır.

Before adding media, verify that it contains no personal data, community identifiers, private endpoints, credentials, proprietary assets, or third-party copyrighted content without permission.

Medya eklemeden önce kişisel veri, topluluk kimliği, özel endpoint, credential, tescilli varlık veya izinsiz üçüncü taraf telifli içerik bulunmadığını doğrulayın.
